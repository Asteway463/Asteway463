### 🌍 EthioExplore

**EthioExplore** is an Ethiopia-focused travel platform designed to help people discover destinations, plan trips, estimate travel costs, and share travel experiences.

#### ✨ Features

* 🗺️ Destination discovery
* 📍 Maps & routes
* 💰 ETB & USD travel cost estimation
* ⭐ Ratings & reviews
* 📸 Photo sharing
* ❤️ Favorite destinations
* 📝 Travel itinerary planning
* 🔐 User authentication

#### 🧱 Tech Stack

`React` • `Node.js` • `Express.js` • `PostgreSQL` • `Tailwind CSS`
